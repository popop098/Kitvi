Kitvi(킷비) · 0.6.0

PC 상태와 커뮤니티 플러그인을 제공하는 Windows용 대시보드입니다.
현재 앱 화면은 한국어입니다. PC 상태는 오프라인에서 확인합니다.
한국어 안내: https://github.com/popop098/Kitvi
English guide: https://github.com/popop098/Kitvi/blob/main/README.en.md
GPU가 여러 개면 GPU 그래프 오른쪽 선택기를 사용합니다. 요약과 그래프가 함께 바뀝니다.
환경이 제공하지 않는 사용률은 — 로 표시하며 0%로 대체하지 않습니다.

실행
1. 자동 업데이트는 Kitvi-Setup-0.6.0-x64.exe 설치형을 사용하세요.
2. 포터블 ZIP은 전체를 새 폴더에 풀고 Kitvi.exe를 실행하세요. exe만 옮기지 마세요.
3. Node.js·.NET·WebView2는 따로 설치할 필요가 없습니다.
4. 관리자 권한이나 인터넷 연결 없이 PC 상태를 확인합니다.

화면
- 상단에서 CPU·GPU·물리 메모리·Windows 정보와 가동 시간을 확인합니다.
- GPU가 여러 개라면 GPU 선택 메뉴로 표시할 어댑터를 바꿉니다.
- 사용률은 1초 간격으로 수집하며 그래프는 최근 60초만 보여줍니다.
- 실행 초기에는 수집한 구간부터 그래프를 그립니다. 빈 구간은 임의로 채우지 않습니다.
- 저장공간은 5초, GPU 목록·모니터·장치는 15초 간격으로 갱신합니다.
- 새로고침 버튼으로 고정 사양과 장치 목록을 다시 확인합니다.
- 장치 목록에서 종류를 선택하거나 이름·제조사를 검색할 수 있습니다.
- 읽을 수 없는 정보는 정보 없음 또는 제공되지 않음으로 표시합니다.
- 용량은 Windows가 보고하는 바이트를 1024 단위로 환산합니다. 제품 표기나 설치 용량과 다를 수 있습니다.
- GPU 사용률은 해당 어댑터의 가장 바쁜 엔진을 기준으로 집계합니다. 작업 관리자와 수집 시점·엔진 설정이 다르면 순간 값이 다를 수 있습니다.
- 장치의 정상 표시는 Windows 장치 상태입니다. Bluetooth 주변 기기의 실제 전원·연결을 추정하지 않습니다.

창 조작
- 앱 상단 빈 공간을 끌면 창을 이동합니다.
- 헤더를 더블 클릭하거나 최대화·복원 버튼으로 창 크기를 전환합니다.
- 오른쪽의 최소화·최대화/복원·닫기 버튼과 Alt+F4를 사용할 수 있습니다.
- 창 가장자리를 끌어 크기를 조정할 수 있습니다.
- 해·달 버튼으로 화이트·다크 모드를 바꿉니다. 선택한 모드와 창 위치는 다음 실행에 복원합니다.

연결 문제
- PC 정보 수집이 중단되면 한 번 자동으로 다시 연결합니다.
- 자동 재연결 후에도 실패하면 다시 연결 버튼을 눌러 재시도하세요.
- 앱을 닫으면 보조 수집 프로그램도 종료합니다.

데이터
- 설정·오류 로그: %LOCALAPPDATA%\Kitvi
- 개인용 구버전과 데이터 위치가 다르며 기존 설정을 가져오지 않습니다.
- PC 상태와 그래프는 외부 서버로 보내지 않습니다. 측정 이력은 실행 중 메모리에만 보관합니다.
- 로그에 PC 스냅샷이나 장치 목록을 저장하지 않습니다.
- 버전 확인·플러그인 가져오기·엔진 설치에는 GitHub 연결이 필요합니다.
- 영상 조회·다운로드에는 YouTube와 영상 CDN 연결이 발생합니다.

업데이트와 플러그인
- 시작 시 자동 확인을 켜거나 끄고, 설정에서 수동으로 새 버전을 확인합니다.
- 설치형은 다운로드 후 다시 시작하여 설치를 직접 선택합니다. 진행 중인 미디어 작업이 있으면 재시작 설치를 막습니다.
- 0.3.0 또는 포터블 사용자는 설치형을 한 번 직접 설치해야 앱 내 업데이트 설치를 사용할 수 있습니다.
- 플러그인에서 popop098/kitvi-YT-downloader를 가져오거나 .kitvi-plugin.zip을 선택합니다.
- 커뮤니티 플러그인 사용은 기본으로 꺼져 있습니다. 처음 켤 때 위험 안내를 읽고 동의하세요.
- 전역 사용 동의와 개별 플러그인 동의는 별도입니다. 설치·활성화 전에 제작자·이메일·출처·권한을 확인하고 동의하세요.
- 이름과 이메일은 제작자가 적은 정보이며 Kitvi가 검증하지 않습니다. 이메일이 없는 기존 SDK 1 플러그인은 미등록으로 표시합니다.
- 플러그인 사용이 켜져 있고 자동 확인을 허용한 경우 GitHub 플러그인의 새 버전을 시작 시와 6시간 간격으로 확인합니다. 설정에서 자동 확인을 끌 수 있습니다.
- 플러그인 목록의 업데이트 확인으로 수동 확인하고, 해당 항목의 업데이트 버튼으로 적용합니다.
- 같은 GitHub 출처·제작자·연락처·권한의 업데이트는 동의와 사용 여부를 유지합니다. 제작자·연락처·권한 변경이나 로컬 ZIP 교체는 비활성화 후 다시 동의해야 합니다. 저장한 설정은 보존합니다. 진행 중인 미디어 작업은 완료하거나 취소한 뒤 업데이트하세요.
- ZIP 설치 플러그인은 새 ZIP을 선택해 갱신합니다. 기존 공개 0.4.0의 플러그인과 엔진은 유지됩니다.
- 플러그인별 켜기·끄기·삭제를 지원합니다. 출처와 체크섬은 제작자 신원이나 안전성을 보증하지 않습니다.
- 예제는 공식 yt-dlp 엔진을 별도 설치하며 SHA256을 검증합니다. 공개 YouTube 개별 영상, 단일 영상/원본 오디오 저장, 진행률·취소를 제공합니다.
- 로그인·쿠키·재생목록·FFmpeg 병합·MP3 변환은 포함하지 않습니다.
- 플러그인 제작 가이드: https://github.com/popop098/Kitvi/blob/main/docs/plugin-guide.md

지원 범위
- Windows 10 22H2·Windows 11 x64 호환성을 대상으로 하는 초기 버전입니다.
- Windows 11 x64에서 검증했으며 Windows 10 22H2는 별도 실기 검증 전입니다.
- Microsoft의 운영체제/.NET 공식 지원 범위와 앱 실행 호환성은 별개입니다.
- 온도·팬 속도·전력, 조명·Steam은 포함하지 않습니다.
- 코드 서명이 없는 Preview입니다. TLS·체크섬을 사용하며 게시자 서명 검증은 제공하지 않습니다.
- Kitvi 소스 코드는 https://github.com/popop098/Kitvi 에 공개하며 Kitvi가 작성한 코드와 문서는 MIT 라이선스입니다.
- 브랜딩과 제3자 구성 요소는 별도 조건을 따릅니다. 저장소의 BRANDING.md, THIRD_PARTY_NOTICES.md와 배포 파일의 라이선스 고지를 확인하세요.
- 보안 취약점 제보: https://github.com/popop098/Kitvi/blob/main/docs/security.md
